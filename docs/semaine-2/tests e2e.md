# Scénario de test manuel — Candidatures

## 1. Consulter les offres

Ouvre la liste des offres et choisis une offre publiée.

**Résultat attendu :**

Le bouton « Candidater » est visible et utilisable.

- [X]Résultat correct
- [ ] Résultat incorrect

## 2. Envoyer une candidature

Clique sur « Candidater », saisis un message facultatif, par exemple : « Je suis intéressé par cette offre et motivé pour rejoindre votre équipe. » Puis valide.

**Résultat attendu :**

La candidature est enregistrée et un retour confirme sa création.

- [X] Résultat correct
- [ ] Résultat incorrect

## 3. Consulter ses candidatures

Ouvre la page ou la section « Mes candidatures ».

**Résultat attendu :**

L'offre apparaît avec le statut « En cours ».

- [X] Résultat correct
- [ ] Résultat incorrect

## 4. Vérifier la persistance

Recharge la page du navigateur.

**Résultat attendu :**

La candidature est toujours présente avec son statut « En cours ».

- [X] Résultat correct
- [ ] Résultat incorrect

## 5. Retirer la candidature

Clique sur « Retirer » ou sur le bouton équivalent.

**Résultat attendu :**

Le statut devient « Retirée » et la candidature ne peut plus être retirée une seconde fois.

- [X] Résultat correct
- [ ] Résultat incorrect
